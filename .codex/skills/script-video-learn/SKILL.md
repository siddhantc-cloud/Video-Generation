# Script Video Learn

Turn observed evidence into repeatable behavior without confusing project taste with universal law.

## Evidence order

1. Encoded artifact, probe data, screenshots, provider response, or command output.
2. Current project files and job ledgers.
3. Human approval or rejection.
4. Inference, explicitly labeled.

## Workflow

1. Identify the new fact, its evidence, scope, and confidence.
2. Classify it:
   - project fact or creative decision;
   - provider-navigation fact;
   - reusable production law;
   - hypothesis needing another reproduction.
3. Update the narrowest project source of truth first.
4. Promote only cross-project learning into `docs/video-production-workflow.md`,
   `video-production-system/`, another narrow recipe, or a `script-video-*` skill.
5. Remove stale contradictory instructions instead of appending duplicate rules.
6. Preserve checklist-first structure and link evidence.
7. Synchronize canonical Codex skills and shared agent definitions to Claude.
8. Run all parity and skill validators.
9. Report what changed, what remains project-specific, and what is still unproven.

## Guardrails

Do not store secrets, raw credentials, customer data, unstable provider prices, or speculative UI behavior as fact. Do not create paid jobs, delete assets, or promote media.

Use project memory only for durable facts that are not already answered by current repository evidence.
