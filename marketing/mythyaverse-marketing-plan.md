## Video Assembly (ffmpeg — local, free)

For each video after generating keyframes and animating in kling 3.0 (web UI):

```bash
# Download all clips from Higgsfield web UI → name them kf1.mp4, kf2.mp4, etc.

# Assemble with captions burned in (done via web UI text overlays, or ffmpeg drawtext)
ffmpeg -i kf1.mp4 -i kf2.mp4 -i kf3.mp4 -i kf4.mp4 \
  -filter_complex "[0:v][1:v][2:v][3:v]concat=n=4:v=1:a=0[v]" \
  -map "[v]" -c:v libx264 -crf 18 assembled.mp4

# Add music (royalty-free, Kevin MacLeod / incompetech.com)
ffmpeg -i assembled.mp4 -i music.mp3 \
  -map 0:v -map 1:a \
  -af "afade=t=out:st=25:d=5" \
  -shortest -c:v copy final.mp4
```

Music: Download from https://incompetech.com (CC-BY, Kevin MacLeod) — curl works fine.
